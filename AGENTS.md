# AGENTS.md — pgscatalog-link

Guidance for agents and contributors working in this repository.

> `README.md` is the front door and follows the **GeneFoundry README Standard v1** (hard
> ceiling 200 lines, fixed section order, machine-checked by `scripts/check_readme.py`).
> Depth lives in `docs/`. Do not grow the README: relocate.

## What this is

`pgscatalog-link` is a read-only MCP server over the official **PGS Catalog REST API**
(`https://www.pgscatalog.org/rest/`, EMBL-EBI / NHGRI-EBI): polygenic scores, traits,
publications and performance metrics. It is one backend in the GeneFoundry `-link` fleet,
federated behind `genefoundry-router` under the namespace **`pgscatalog`**. Scaffolding (MCP
plane, Docker, CI) was lifted from `ucsc-link`. Tracking issue:
https://github.com/berntpopp/genefoundry-router/issues/288.

## Two planes (non-negotiable boundary)

- **Data plane** — `config.py`, `ratelimit.py`, `api/`, `service.py`. Calls the PGS Catalog
  over async httpx, validates IDs, returns **plain dicts**, raises typed
  `pgscatalog_link.exceptions` errors. Never builds envelopes.
- **MCP plane** — `mcp/`. `run_mcp_tool` (`mcp/envelope.py`) owns `success`/`_meta` and turns
  exceptions into **returned** `isError` envelopes (never raised to the client).

## Invariants

- **Live API only, no data snapshot.** Nothing is stored beyond the in-process TTL cache in
  `api/client.py`.
- **Unknown IDs are `not_found`.** Upstream answers HTTP 200 `{}` for an unknown score, trait
  or publication; the data plane maps that to `not_found`, never an empty success.
- **Obsolete trait IDs.** The catalog migrated many EFO trait IDs to MONDO; an obsolete ID
  answers empty. That is `not_found` naming `trait_id`, with a hint to call `resolve_trait`.
- **Paging.** Upstream rejects `limit` > 250 with a 400. The tools cap `limit` at 50
  (a performance row carries one fenced `reported` block, so 50 rows stay under the 128-object
  fence cap) and never forward a larger value.
- **Honesty.** `total` is the upstream `count`; `truncated` is true whenever rows were
  withheld.
- **Licences verbatim.** Each score's author-set `license` (some CC BY-NC-ND) is passed
  through unchanged; never summarise or drop it. Ancestry distribution (development and
  evaluation) is surfaced on every score.
- **Scoring files are linked, never streamed.** Return the FTP/HTTPS URLs; never download or
  proxy a scoring file.
- **Politeness.** Every upstream request passes the process-wide `RateLimiter` (default 0.6 s
  spacing, about 100/min, 20,000/UTC day). Do not bypass it, including in live tests. The
  User-Agent names the product, version and project URL only — never user data.
- **Untrusted text.** Upstream prose (trait descriptions, publication titles) is fenced with
  `fence_untrusted_text`; upstream error bodies are only used to classify, never echoed
  (fixed messages in `api/client.py`).
- **6-code error taxonomy**: `invalid_input`, `not_found`, `ambiguous_query`, `rate_limited`,
  `upstream_unavailable`, `internal`.
- Tools publish no `outputSchema` (Tool-Surface Budget Rule 3); every input property has a
  description, required ones carry `examples`, closed vocabularies are `Literal` enums.
- Keep `mcp/capabilities.py::TOOLS` equal to the registered tool set and the README `## Tools`
  table in sync (both tested).

## Fleet deploy contract

`docker/docker-compose.npm.yml` (deployed by the fleet controller `strato_v6_docker_npm`)
declares `user: "10001:10001"` — this image's own uid:gid from `docker/Dockerfile`. `user` must
NOT appear in `docker/docker-compose.yml` / `docker/docker-compose.prod.yml` (the release gate
forbids it). Guard: `tests/unit/test_deploy_overlay_user.py`. Both reusable-workflow pins
(`container-ci.yml`, `container-release.yml`) track the same `genefoundry-router` revision.

Release checklist: bump `pyproject.toml`, `uv lock`, `CHANGELOG.md` heading
`## [x.y.z] - YYYY-MM-DD`, `CITATION.cff` `version:` (generated by the router's
`make citation-write`), tag `vx.y.z`, approve the `release` environment gate via
`gh api repos/berntpopp/pgscatalog-link/actions/runs/<id>/pending_deployments` (it can gate more than
once). **Never `gh release create`** — the workflow creates the immutable release.

## Definition of done

`make ci-local` green: format-check, lint-ci, lint-loc (≤500 lines/file), lint-readme,
lint-surface, mypy `--strict`, tests. Unit tests are network-free: `respx` replays recorded
PGS Catalog responses. Live checks are opt-in
(`make test-integration`, a handful of polite calls).

## Make targets

```
make install          # uv sync --group dev
make ci-local         # the definition-of-done gate
make test             # unit tests
make test-integration # live PGS Catalog calls (opt-in, rate-limited)
make dev              # unified HTTP server on 127.0.0.1:8000
make mcp-serve        # stdio MCP server
make docker-up        # Docker stack; make docker-url prints the MCP URL
```

## Conventions

- Python 3.14, `uv`, hatchling; structlog to **stderr only** (stdout is the stdio protocol).
- TDD: failing test first. Files under 500 lines.
- `tests/conformance/` and `scripts/check_readme.py` / `scripts/surface.py` are vendored
  byte-identical from `genefoundry-router`; do not edit them here.

Research use only; not for clinical decision support. PGS Catalog data are subject to the
EMBL-EBI Terms of Use and each score's own licence.
